# Fit/Gap анализ.

#### Список систем: 
1. ИС Алмазы: отбор алмазов, планирование работ, присвоение идентификаторов и подготовка ведомостей, ведение учета камней на собственных серверах, публикация реестра алмазов для покупателя на собственном сайте. 
Необходимые доработки: 
- закупка и разворачивание инфраструктуры
- разработка площадки/сайта для проведения онлайн аукционов
- проектирование БД
- настройка интеграций

2. ИС Лаборатория: оценка и оцифровка алмазов, передача реестра алмазов в электронном виде
3. ИС Логистика: транспортировка алмазов из офиса в лабораторию и обратно, доставка заказов покупателю в любую точку земли.
4. ИС Аукцион: проведение онлайн аукциона на собственных серверах.
Необходимые доработки: 
- разработка интерфейса для проведения аукциона
- регистрация пользователей
- оформление заявок
- оформление заказов
- система контроля и учета 

5. ИС Бухгалтерия: ведение контрактов, учет, оплата услуг.
Необходимые доработки: 
- интеграция с платежной системой
- автоматизация оплаты

6. ИС Платежная система: новая


#### Список интеграций: 
1. ИС Алмазы- ИС Лаборатория: новая, получение электронного реестра оцифрованных алмазов 
2. ИС Алмазы - ИС Аукцион: существующая, публикация реестра, управление заказами, заявками
3. ИС Алмазы- ИС Бухгалтерия: существующая, передача данных о платежах
4. ИС Бухгалтерия - ИС Логистика: существующая, оплата услуг лаборатории, логистики
5. ИС Алмазы - ИС Платежная система: новая, проведение платежей
